# Repository notes

- Buildless HTML/CSS/JavaScript site. `index.html`, `style.css`, and `app.js` implement the course landing page. No package manager, build step, server application, or automated email service is configured.
- Registration entry: `inscricao.html`; separate paths: `inscricao-online.html` and `inscricao-instrucoes.html`. Registration styles and behavior are isolated in `registration.css` and `registration.js`.
- Registration is browser-only. Online review downloads a PDF named `<normalized-full-name>_formulario-inscricao.pdf`; `registration-pdf.js` renders paginated A4 images locally to preserve Unicode text. PDF text is rasterized, so the HTML review remains the accessible text version. No backend, persistence, or automatic email delivery is configured.
- Both paths require the applicant to sign the document and email it to `especializacaorha@ufrgs.br`. Mailto URLs contain only a subject; applicants attach and send manually.
- Public blank form: `assets/registration/formulario-inscricao.docx`, copied byte-for-byte from the supplied registration DOCX. Keep this public copy synchronized with approved source changes.
- Preview using `python3 -m http.server 8000` from the repository root, then open `/inscricao.html`. Focused static checks: `python3 tests/check_registration.py` and `python3 tests/check_profiles.py`; also run `git diff --check`. Browser verification is separate from these checks.
- Commit completed changes; do not push unless explicitly requested. Stage only task changes: pre-existing edits may share `index.html`, `app.js`, and `style.css`.

- Faculty photos: `assets/profiles/<slug>.png`; `profileSlug` in `app.js` removes accents and punctuation and joins lowercase words with hyphens. Use `teacherPhoto` for generated faculty displays, and `data-teacher` for static coordinator/contact names. Photos are resized to at most 168px for the 22–42px displays. Photo filenames correct the supplied Norma surname typo to Pagnoncelli.
- Card back faces scroll as a whole. Keep pointer events disabled on the hidden face so the front does not intercept wheel/touch input after rotation. Space scrolls an already open card; Enter toggles it.
- `docs/plano-migracao-ufrgs.md` is the primary UFRGS deployment plan: static files via SFTP, no database required. Remote document root, HTTPS, and the production submission channel remain unverified. `wordpress-migration/README.md` is an alternative only if WordPress is required. Never include credentials or internal source documents in a public deployment package.
- Editais: homepage navigation links to `editais.html`. To publish an approved PDF, put it in `assets/editais/` and add a `{ title, file }` entry to the `editais` array in `editais.js` (relative path, e.g. `assets/editais/edital-selecao.pdf`). Deploy the PDF and updated script together. Empty array shows an unpublished notice; entries render native PDF viewers with open/download links for browsers without inline PDF support. No upload service is configured. Styles are isolated in `editais.css`.

- Display full dates as `dd/mm/yyyy`. Registration date fields use text inputs with explicit format and calendar validation so browser locale cannot switch the display to month-first. Review and PDF preserve this format.
